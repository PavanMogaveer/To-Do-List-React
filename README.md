# 📝 Task Management App

A simple and responsive Task Management App built using **React** . This app helps users efficiently manage their tasks with features like task history, customizable views, and real-time updates.

## 🚀 Features

- ✅ Add, edit, and delete tasks
- 📌 Mark tasks as completed or pending
- 📱 Fully responsive UI

## 🛠️ Technologies Used

- **Frontend:** React, Tailwind CSS  
- **State Management:** React Context API
